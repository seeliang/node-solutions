# Puppeteer Crawler

This project is a simple Node.js application that uses Puppeteer to crawl a website and retrieve cookies.

## Prerequisites

- Node.js (version 12 or later)
- npm (Node package manager)

## Installation

1. Clone the repository:

   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```
   cd puppeteer-crawler
   ```

3. Install the dependencies:

   ```
   npm install
   ```

## Usage

1. Open `src/index.js` and modify the URL variable to the website you want to crawl.

2. Run the application:

   ```
   node src/index.js
   ```

3. The cookies from the specified website will be logged to the console.
